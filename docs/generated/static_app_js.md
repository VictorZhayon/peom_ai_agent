# static/app.js

This file contains the JavaScript code for the frontend of the poem AI agent, handling user interactions, API calls, and dynamic content rendering. It includes functions for UI manipulation, poem generation and display, history management, and various utility functions.

## pick

```javascript
function pick(arr) { return arr[Math.floor(Math.random() * arr.length)]; }
```

Selects a random element from the given array.

**Parameters:**

*   `arr`: The input array.

**Returns:**

*   A randomly selected element from the array.
